2. Use LLMs to group and create better question

Input: The LLM is given a set of cards
Output: The LLM give us back a new set of cards

Example:
def __init__(self, config, data):
        self.config = config
 
        chars = sorted(list(set(data)))
        data_size, vocab_size = len(data), len(chars)
        print('data has %d characters, %d unique.' % (data_size, vocab_size))
 
        self.stoi = { ch:i for i,ch in enumerate(chars) }
        self.itos = { i:ch for i,ch in enumerate(chars) }
        self.vocab_size = vocab_size
        self.data = data
Source: Taken from mingpt/chargpt/chargpt.py

As an example instead of asking what's left and what's right? It should realize that stoi, itos, vocab_size, data is one block.
It should tell us to pick which variables do we need to define next in a choose 4 out of 10 style question.
