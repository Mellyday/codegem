import { clerkMiddleware, createRouteMatcher } from "@clerk/nextjs/server";

Step 2: Get a Test JWT from the Clerk Dashboard
Go to your Clerk Dashboard.
Navigate to JWT Templates.
Create a new template or use the default one.
On the template page, you can select a user and generate a short-lived token specifically for testing. Copy this token.
Step 3: Use the JWT in your curl Command
Now, use the generated JWT in the Authorization header as a Bearer token.
code
Bash
# Replace <YOUR_CLERK_JWT_TOKEN> with the token from the dashboard
export CLERK_JWT="<YOUR_CLERK_JWT_TOKEN>"

curl -X POST "http://192.168.100.55:3001/api/repos" \
-H "Content-Type: application/json" \
-H "Authorization: Bearer $CLERK_JWT" \
-d '{"url":"https://github.com/karpathy/minGPT"}'
This is the recommended way to test Clerk-protected APIs because:
It's secure.
It mirrors how a real front-end application would authenticate.
You don't need to modify your API code with insecure backdoors like the x-user-id header.
